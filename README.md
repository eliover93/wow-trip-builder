# Travel Weaver Pro

Quiero crear una servicio para vender a las agencias de viaje, se trata de un programa que crea paquetes de viajes de forma dinamica y visual efecto wow, animaciones presupuestos, cosas que hacer cada dia, este proyecto tendra varias partes, un backoffice muy intuitivo y facil de rellnar con todos los datos del viaje, y un front end donde el cliente de la agencia de viaje quedara impresionado de ver sus viajes, el proyecto tiene que ser rehusable para las agencias y necesito tambien una demo para mostrarlas y vender este producto, a continuacion te escribo una url de un ejemplo parecido a lo que estoy buscando  https://3rn22z65qr7ts.kimi.page/
